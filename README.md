# Shopping Cart Application

A responsive shopping cart application built with React, TypeScript, Vite, Bootstrap, Zustand, TanStack Query, and Zod.

## Tech Stack

- React 19
- TypeScript
- Vite
- Bootstrap
- Zustand
- TanStack Query
- Zod
- pnpm

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/ARUN-KR07/taskshopping.git
```

### 2. Navigate to the Project

```bash
cd taskshopping
```

### 3. Install Dependencies

```bash
pnpm install
```

### 4. Start the Development Server

```bash
pnpm dev
```

The application will start on the local development URL provided by Vite.

## Build

To create a production build:

```bash
pnpm build
```

## Preview Production Build

```bash
pnpm preview
```

## API
